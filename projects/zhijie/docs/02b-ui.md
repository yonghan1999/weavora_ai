## 视觉设计目标

延续用户已确认的炭黑与荧光黄绿风格、游戏房间卡片及玩家语音头像，不重新设计信息架构。品牌统一为“织界 / WEAVORA”。大厅优先、私密群组、独立语音/联机状态及常驻语音条保持不变，避免引入频道树、好友私聊、公开搜索等新功能。

本阶段不再仅调整样式。以固定小队的重复使用为设计假设，将页面标题改为可定位的功能名称，按“识别对象 → 判断状态 → 执行动作”重组大厅和群组卡片；当前活动用独立通道状态代替概念装饰；联机页压缩重复教学，优先展示队友地址。补充实际字段错误反馈、取消焦点与可操作组件状态工作台，形成可交接的属性、事件、异常时序和布局契约，详见 [UI 开发交接契约](02b-ui-handoff.md)。

退出登录始终确认，未入房无额外解释；有房间活动时仅说明语音和联机中断。群邀请保持在“我的群组”列表工具栏右侧，不与创建群组争夺主操作层级。没有用户研究结果，不把设计判断冒充经过用户验证的结论。

## 设计系统

令牌及组件样式位于 `workspace/design/ui/ui.css`，呈现适配位于 `presentation.js`；复用 B1 域逻辑，不复制权限/加入/恢复实现，遵循 DRY、KISS。适配只负责视图、语义、焦点和内联反馈，不把它作为正式生产组件架构。不引入框架、图标包、在线字体或图片依赖，遵循 YAGNI。`system.html` 直接复用同一套样式，展示可操作的等待、重试、字段校验与修正。

## 组件与交互状态

| 组件 | 默认/悬停/按下 | 选中/禁用/错误与恢复 |
| --- | --- | --- |
| 主按钮 | 黄绿底深色文字；悬停增亮；按下内描边，无位移 | 禁用灰化、无悬停动效；不将禁用当作权限校验 |
| 次按钮/图标按钮 | 中性表面；悬停显边界；保留名称 | 所有可操作按钮有键盘焦点环；邀请/消息菜单默认可见 |
| 危险操作 | 浅红文字及边框，不默认填满主色 | 确认前明确影响；删除/解散保留不可恢复提示与名称校验 |
| 导航/页签 | 中性文字、悬停底色 | 选中同时有底色/边线与文字差异；不只依赖颜色 |
| 输入/选择/音量 | 可辨边框、标签、深色原生选项 | 焦点 2 px 外环；既有字段错误持续内联、关联输入并保留原值；编辑后清除旧错误，不重复播报；真实服务校验待接入 |
| 独立连接标签 | 未连接/连接中/重试中/受限均文字表达 | 成功黄绿，失败浅红并有文字原因和重试；另一通道不被隐藏或强行断开 |
| 玩家卡片 | 姓名、语音文字、头像与操作分层 | 说话有边框及文字，静音有图标及文字；关闭动效不移除状态 |
| 邀请角标 | 次级文字入口，有待处理才显示数字 | 零待处理无数字 0；入口仍可查看历史；可访问名称含待处理数量 |
| 对话框 | 语义 dialog、标题/说明关联、背景 inert、内部滚动 | 表单优先首字段；确认类优先底部取消而非右上角关闭；Tab 循环、Escape 取消、关闭返回触发点；仅确认按钮执行退出 |
| Toast/空状态 | Toast 使用礼貌播报区域；空状态提供下一步 | 常规状态可直接识别时不重复提示；错误保留原因和可恢复入口 |

基础模拟脚本原样复用 B1，所有敏感操作仍按执行时当前群/房间资格检查。UI 不新增授权逻辑，不将图标隐藏作为安全机制。实际异步防重复、服务端失败回滚的开发契约与组件样例分开标注，不用组件定时演示假装真实后端完成。

## 响应式与可访问性

桌面主视口 1440×900；900 px 与 600 px 用于窄窗口适配，不据此承诺原生移动端支持。

- 大于 1220 px：大厅有在线好友侧栏；房间玩家区与联机侧栏并列。901–1220 px：收起好友侧栏，联机栏至少 340 px，避免地址和复制按钮挤压。
- 900 px 及以下：房间玩家区在上、聊天/联机/成员区在下；玩家卡两列、群卡单列；设置页签横排；标题栏保留窗口控制。16 人成员区独立滚动，不挤压聊天发送框。
- 600 px 及以下：房卡单列、玩家卡两列；底部主导航保留设置和账号；群聊侧栏上下布局；弹框内边距 16 px、底部操作区固定可见，确认按钮至少 44 px；设置项换行，输入/选择与发送框不撑破页面。
- 主/次/弱文本在指定深色基础表面上目标对比度至少 4.5:1；主按钮深色文字与黄绿背景至少 4.5:1。测试只覆盖明确列出的组合，不宣称所有渐变、透明合成、原生控件或整站 WCAG 认证。
- 所有键盘操作有 2 px 可见焦点，普通按钮约 40 px、小型操作至少 32–34 px，触屏弹框确认至少 44 px。默认可见邀请/消息操作，避免仅鼠标悬停才能发现。
- 状态不能只靠颜色；动态减弱遵循 `prefers-reduced-motion`；文件不加载在线字体。语义、焦点与背景隔离沿用已验证 B1，不复制处理逻辑。

## 可点击 UI 原型

- 入口：`workspace/design/ui/index.html`
- 与低保真原型的差异：任务导向页面标题、卡片信息/操作层级、紧凑当前活动、联机指引、内联校验反馈、确认取消焦点、语义与组件状态规范。群邀请位置、退出确认、权限及所有业务状态不变。
