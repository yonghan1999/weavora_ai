# 产品原型设计：织界 WEAVORA

> 品牌名称：中文为“织界”，英文统一使用“WEAVORA”，不再使用“ZHIJIE”作为产品英文标识。内部工作流项目标识 `zhijie` 仅用于文件与审批追踪，不属于产品品牌。

> 状态：B1 产品原型改基线候选。依据新批准的 `docs/02-requirements.md`（REQ-001～REQ-029、AC-001～AC-048），批准记录 `APR-B-0ebffa236a4e`。本轮补齐仅控制面与 Lighthouse 的客户端直传、副本同步和语音隧道依赖交互；页面仍为本地模拟，不验证真实上传、持久化、语音、虚拟网络、性能、安全、邮件投递或平台兼容性。旧 B1/B2 批准不沿用。

## 设计目标与范围

织界桌面端以“玩家大厅”为日常入口，以“游戏房间”为组队与联机核心，以“私密群组”为长期社交关系。主任务不是浏览频道，而是回答三个问题：**谁在玩、下一局去哪、怎样马上连上**。

本轮视觉采用炭黑、荧光黄绿、游戏房卡片与玩家语音头像，区别于此前 KOOK 参考方案的绿色频道栏和 Discord 式紫蓝配色。高保真外观用于帮助确认产品方向，最终设计令牌、组件细节与跨平台适配仍在 B2 确认。

首版仍覆盖邮箱账号、好友、私密群组、邀请与群主治理、角色权限、持久房间、16 人容量、单设备活动、断线恢复、分域语音/网络状态、消息、只读管理记录和支持矩阵。明确不提供好友私聊、公开群搜索、游戏自动发现、互联网代理、物理 LAN 转发、支付和独立封禁后台。

### 核心产品决策

1. **大厅优先于频道**：登录直达玩家大厅，首屏展示当前队伍、可加入游戏房间和在线好友，不设置多栏频道树。
2. **房间就是主战场**：玩家头像和说话状态占据主区域；聊天、联机和成员是房间右侧三个并列页签。
3. **入房后语音始终触手可及**：未加入房间时底部语音条完全隐藏且不占布局空间；加入后跨大厅、好友、群组和房间持续显示，可静音、关闭接收、调整设备或离开，退出房间后再次隐藏。开麦不等于正在发言，只有独立语音活动状态成立时才显示“发言中”和声波。
4. **联机只做必要三步**：确认实际游戏主机成员并复制其虚拟 IP → 游戏内选择直接连接 → 粘贴地址。网络细节不混入社交成员列表。
5. **社交与管理分层**：好友和群组有独立导航；群成员、邀请、角色、只读管理记录和危险操作收进群组管理对话框。
6. **状态不互相冒充**：语音等待虚拟隧道就绪；音频专属故障独立恢复，隧道故障影响依赖它的语音和传输；任何延迟、在线或兼容状态均为模拟展示，不作为真实能力证据。
7. **设置导航保持一致**：语音与设备、账号与设备、安装与支持统一使用左侧页签、右侧内容的页内切换，不在同级页签之间混用弹框；设备、音量和偏好跨页签保留。只有设备转移等需防误触的确认步骤使用对话框。

```text
未认证区
├─ 登录 → 玩家大厅
├─ 注册 → 邮箱验证码 → 玩家大厅
└─ 找回密码 → 已验证邮箱重置

已认证桌面壳
├─ 顶部：产品标识 / 模拟数据标识
├─ 左侧主导航
│  ├─ 大厅：当前活动（仅入房后）+ 游戏房卡片 + 在线好友
│  ├─ 好友：筛选、昵称/账号 ID 搜索、资料卡、申请与组队邀请
│  ├─ 群组：私密群组卡片 → 长期群聊 → 群组管理
│  ├─ 创建：创建持久游戏房间
│  └─ 设置：语音设备、账号设备、安装支持、退出
├─ 游戏房间
│  ├─ 主区域：玩家头像、房主、说话与静音状态、邀请队友
│  └─ 右侧页签：聊天 / 联机 / 成员
└─ 入房后的常驻语音条
   ├─ 当前房间与双通道摘要
   ├─ 静音 / 关闭接收 / 设备 / 离开
   └─ 独立网络连接状态
```

全局搜索、通知中心、拓扑动画和无真实探测的精确延迟不在首版原型展示。所有房间、成员、房主、IP、好友关系、群人数与消息均由统一模拟数据派生，操作后同步更新页面。

窄窗口优先收起大厅右侧好友栏；900 px 及以下房间改为玩家区在上、聊天/联机/成员区在下，600 px 及以下主导航转为底部横向布局并保留设置与账号入口。移动端属于布局适配示意，不代表原生移动端或完整平台兼容性承诺。

## 核心流程

### 1. 注册、登录与找回

注册邮箱 → 提交验证码 → 成为已验证账号 → 登录直达玩家大厅。未验证时不能访问好友、群组或房间。找回只通过已验证邮箱，不提供人工绕过入口。

### 2. 好友与群组

搜索账号 → 发送好友申请 → 对方接受/拒绝 → 更新好友列表。点击好友资料卡可复制账号 ID 或邀请组队；首版无私聊。群组只通过私密邀请进入，长期保存消息和房间。当前群成员可邀请，撤销待接受邀请仅群主/管理员。

群组页主标题区仅保留“创建群组”主操作；“群邀请”收敛至“我的群组”列表工具栏右侧，采用弱化图标文字入口。有待处理邀请时显示数量角标与可访问名称，无待处理时不显示数字 0，入口仍可查看历史邀请。窄屏保持列表标题和邀请入口同一行，不新增导航或业务状态。

### 3. 快速组队与加入

大厅点击“创建房间” → 填写房间、游戏、所属群、描述和可选密码 → 创建并进入。容量固定为 16 人，只有所属群群主/管理员可以创建。群内创建默认选中当前群。加入已有房间时所有入口共用群籍、开放状态、容量和密码检查；切换失败保留旧有效活动。成功后先建立虚拟网络，再自动连接语音；加入资格成功不代表所有成员已直连。

### 4. 房间语音与文字

进入房间 → 玩家头像展示说话、静音与连接状态 → 底部语音条随时控制本地设备 → 右侧“聊天”发送房间文字。成员音量只影响本地接收，关闭接收不修改其他成员设置。

### 4a. 消息与媒体完整路径

群聊要求当前有效群籍；房间消息要求本机持有当前活动资格且不处于断线保留。管理员/房主未入房时没有房间聊天旁路。房间历史依附活动：同活动恢复可补读，结束后不可读，新活动为空；群历史不受结束单个房间影响。原型仅保存在当前页面，不证明重启持久化。

文字为 1～4000 Unicode 码点；错误保留输入，失联/失权不显示成功。作者删除本人消息；群主/管理员仅在当前有权会话中代删，房主不因此获得代删权限。删除保留占位并撤销本地附件引用，代删追加本群只读记录。正式服务还须验证旧游标、下载及在途 Range 读取撤销。

媒体流程：选择文件 → 本地预览检查 → 模拟直传 → 模拟接收端校验 → 模拟等待对端落盘确认 → 消息收据。原型仅在当前页面内使用临时 URL 与定时器，不建立真实连接、不写入客户端持久库、不执行安全扫描，不能把状态文案当成实际对端接收。

- 有授权可达成员时展示“对端已接收（模拟）”；部分成员不可达时展示“部分送达 · 其他成员待同步”；没有可达成员时仍可本机暂存，标“本机保存 · 待同步”，不显示已送达。
- 群/房间聊天顶部显示副本状态和“重试同步”，无在线可达副本时提示“缺失内容暂不可用”；已存在本机内容保留，不将缺失内容伪装为空历史。群同步无需先入房，群内容通道不授予跨房游戏/语音权限。
- 选择限制沿用图片 JPEG/PNG/WebP ≤10 MiB、2000 万像素；MP4 ≤100 MiB、120 秒、1080p。收发端完整探测、重编码和恶意文件检查仍未实现；浏览器预览只用于交互。
- 模拟传输有进度、防重复、持续错误、重试和取消。无对端时最终为待同步；资格、网络和配额在各模拟回调重查，活动改变丢弃迟到结果。接收确认丢失、真实断点传输和幂等协议须后续实现。
- 10 GiB 为群附件逻辑引用预算，非服务器存储容量或所有客户端磁盘总量；磁盘满拒收、不静默删除历史。15 分钟草稿过期及 24 小时运行/启动清理按需求交接，原型只模拟草稿过期，不宣称物理清理。
- 删除保留 tombstone；同步只修改未删除消息的待同步收据，不复活已删除附件。正式客户端须上线先同步权威删除/撤销再提供内容，原型不验证离线节点安全。

`?review=1` 的“原型复核工具 → 内容副本与直连”可切换在线副本、无在线可达副本、部分成员不可达；“NAT 直连失败”会让网络失败、语音等待，提示无服务器回退。媒体弹框复核失败、配额、草稿过期、失权和接收端校验失败。正常入口不显示故障按钮。

### 5. 游戏内手动联机

房间右侧“联机” → 确认实际游戏主机成员并复制其虚拟 IP → 游戏内选择“直接连接 / 输入 IP” → 粘贴地址。界面明确不依赖广播发现，不自动发现游戏，不代理互联网，不转发物理 LAN。

### 6. 离开、切换与恢复

退出会撤销本次语音、虚拟网络、旧恢复和设备活动资格，持久房间保留。切房/设备转移先预检目标并保留仍可用的旧活动，再原子替换，任何时刻不双活动。短时断线在 60 秒保留期内以同账号同设备恢复并保持原 IP；超时重入按新会话处理，安全可用时优先尝试原地址。

### 7. 房间与群治理

结束活动清退成员并终止语音/网络但保留房间配置及暂停状态；删除房间终止全部会话和恢复。群主转让须指定成员接受；群主退出前必须完成转让或解散。解散后产品内不可查看或恢复群、消息、房间、邀请和管理记录。

| 类别 | 原型表达 |
| --- | --- |
| 加载与连接 | 服务、语音、网络分别表达，不用一个全局成功覆盖所有分域 |

## 可点击原型

### 本轮客户端直传改基线验证与交接

### 提示文案规范

- 常规行为不解释，界面已有明确反馈时不重复弹出成功提示；仅保留操作中断、数据损失、失败原因和下一步。
- 退出登录始终显示“退出登录？”及“取消 / 退出登录”，未入房不附加说明；入房、连接中或断线保留期间额外提示“退出登录将离开当前房间，并断开语音和联机。”。取消或 Escape 关闭弹窗，不退出账号。
- 移除退出不删数据、好友不授予群权限、重复加入幂等等常识或实现说明。静音与关闭接收由按钮状态反馈；技术边界集中在帮助，不在聊天、联机和设置中反复说明。
- 保留删除与解散不可恢复、切房与设备转移的实际影响、容量/密码/权限错误及实际游戏主机 IP 指引。模拟声明集中在顶部，登录凭据、媒体预览和设备测试保留必要的真实性与安全边界。
- 统一退出逻辑清理连接、恢复计时与旧提示，不改动群组、房间配置或消息。遵循 KISS、DRY，不新增业务能力，也不修改已批准需求。
