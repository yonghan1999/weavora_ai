# 织界用户体验目标与提审条件

2026-11-23 · 开发规划 · 本轮先验证 Windows 首次使用体验。正式交付仍须按既有需求逐平台验收。

## 核心体验

两位第一次使用织界的玩家，各自在自己的电脑上从同一个安装包开始，通过邀请进入同一房间，能听清对方，也能在一个约定的受支持游戏中加入同一局。交给玩家的材料只有安装包、可用邮箱和房间邀请。服务器、证书、邮件投递和语音中继由测试组织者预先准备。

以下时间与人数是本轮建议的验收目标，尚无通过记录。

| 场景 | 普通玩家应能完成的操作 | 通过条件 |
| --- | --- | --- |
| 首次安装与升级 | 双击安装，用普通权限打开桌面端。升级后从原入口打开 | 安装和升级均通过图形界面完成。确需提权时，由软件说明用途并唤起系统确认。全过程手输命令、查进程号、复制驱动或 EXE、配置服务器地址的次数均为 0。拒绝联机提权后，仍可使用文字和语音，并可在界面内再次授权。 |
| 注册与进房 | 收到验证码，完成验证，打开邀请进入房间 | 使用新账号的一对玩家从打开安装包到双方首次听清对方，目标 5 分钟内。计时包含安装、邮件等待和入房；测试人员可从普通用户入口收信。已安装并登录的用户，打开有效邀请后至多再确认一次即可进房。 |
| 音频设置 | 进房前打开设置，选麦克风和耳机，看输入电平，播放测试音 | 语音服务器离线时仍能列出本机设备并在本地试音。分别测试没有麦克风、权限被拒、拔出当前设备和语音服务离线，四种情况均显示对应原因与下一步。录音权限仅在需要采集时请求。 |
| 房间语音 | 两端进房并相互说话；静音后再恢复 | 两端各说一条现场随机短句，对方均能正确复述；双方分别验证静音与恢复。保留两端结果与时间。两端处于“已连接”只算连接检查，通过听辨才算通话成功。 |
| 游戏联机 | 从房间启用联机，按提示授权，用同伴地址加入游戏 | 同一房间内两台真机各获有效虚拟地址，一人建局、一人加入，并共同游戏至少 10 分钟。覆盖 Helper 未启动、用户拒绝提权和网卡初始化失败，界面均能指出下一步。修复条件后单击“重试联机”即可恢复，已有语音继续工作。 |
| 故障与恢复 | 用户能说清哪里出了问题、下一步点什么 | 分别中断控制面、语音服务和联机中继，核对故障归属；语音服务离线时显示“语音服务暂不可用”，保留本机设备列表。短暂故障消失后自动恢复或一次点击恢复。持续故障提供复制诊断信息入口，内容不含密码、验证码和令牌。 |

## 提审前怎样测

1. 测试组织者记录候选包版本和 SHA-256、系统版本、音频设备、游戏及版本，确认邮件、控制面、语音和联机后端都可用。使用与用户收到的同一制品。
2. 安排至少两对首次使用的玩家，每对使用两台独立 Windows 电脑和两个普通账号。至少一轮从干净安装开始，另做一次从上一候选版升级的回归。组织者只给任务，不口头指导。按每对记录完成时间、求助次数、失败步骤及两端实测结果。
3. 任一对需要研发人员介入、触碰终端或手工修包，核心旅程即判失败。核心旅程、表中故障恢复用例及已有发布阻断用例均须通过；修复后以同一最终候选包重新取证。
4. 提审资料附逐项结果、脱敏日志和可复核的双端记录。缺第二台设备、真实听辨或共同游戏记录时，对应项标记“未验证”，保留在开发或测试阶段。本机枚举音频设备、驱动启动、健康检查和构建成功各自只证明该单项。

## 规划时发现的问题（返工前）

- Windows 能枚举 6 个输入和 10 个输出；当前桌面端依赖已建立的语音会话才展示设备，本轮测试服也未部署语音服务。优先打通离线设备设置与双人通话。
- 本轮安装和故障处理曾要求用户手工复制 Helper、查 PID、执行管理员 PowerShell。优先交付图形化安装、授权、升级及恢复路径。
- 现有证据尚不能证明两台设备完成真实通话和游戏互通。准备双端环境后，按上述核心旅程复测。
