## 故障矩阵（与正常旅程分开）

逐项记「实际提示／恢复操作次数／另一个通道是否持续工作／证据编号」。不能只写“连接成功”。测试服务故障只应在获授权的专用环境模拟，不修改生产服务或用户隐私设置。

- 无麦克风、拒绝麦克风权限、拔出当前设备、语音服务离线时本机列表与试音。
- Helper 未启动、取消说明框、拒绝系统授权后继续文字和语音、再次授权、网卡初始化失败后单独重试联机。
- 分别中断控制面、语音服务、联机中继并恢复；持续失败时从普通用户入口复制诊断，核对无凭据和令牌。
- 关闭后升级、重新启动；确认无需命令或手工替换文件。拒绝提权不应等同于退出房间。
