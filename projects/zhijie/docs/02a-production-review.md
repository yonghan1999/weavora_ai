## 结论与范围

本轮按生产交接所需的界面规则修正原型：入口一致、执行时权限、失败可恢复、危险操作确认、状态与数据同步、可重复测试。这里的通过仅针对本机浏览器中的模拟交互；不能据此宣布正式产品达到生产标准。B2 视觉设计、真实服务、持久化、三平台安装、媒体与网络仍须在后续阶段实现并独立验收。

结果状态：`waiting_human`。不推进 B2，不执行生产部署，不替代人工审批。

## 修正与设计依据

| 问题 | 修正 | 原则 |
| --- | --- | --- |
| 邀请码绕过暂停、容量和群资格 | 所有加入路径共用 `joinError`；失败保留旧活动 | DRY、单一职责 |
| 普通成员管理他人房间、旧页面失权仍可保存 | 群级角色与房主分别判定；敏感操作再次检查 | 最小权限、接口职责明确 |
| 群内创建归属错误 | 默认选择当前群，仅列出有创建权限的群 | KISS |
| 邀请和群主转让只提示成功 | 实际模拟待接受、接受、拒绝、撤销、失效和转让接受状态；普通用户有群邀请入口 | 状态驱动、避免伪成功 |
| 治理缺少实际操作 | 成员列表、管理员变更、移出、退出、群资料、解散名称确认、房间删除与房外管理 | 需求驱动、YAGNI |
| 管理记录硬编码 | 操作即时追加本群记录，包含时间、操作者、目标、操作和结果；无编辑入口 | 单一数据源 |
| 双通道同一成功回调、旧结果可复活 | 分开定时器与错误状态，活动代次校验；退出/失权清理待处理结果 | 单一职责 |
| 断线与设备转移缺少失败路径 | 保留期恢复、超时释放、目标预检失败保留旧活动、成功撤销旧端资格 | 失败可恢复 |
| 邮箱验证无错误状态 | 邮箱格式、密码长度、验证码错误/过期/重发、模拟重置步骤 | 可验收性 |
| 社交展示数据矛盾 | 模拟成员活动去重，好友房间状态由当前成员数据派生；退群后隐藏群内容 | DRY |
| 头像过大、联机区狭窄、IP 裁切 | 紧凑玩家卡片、扩大联机栏、明确 IP 行高、窄屏独立滚动 | 信息优先 |
| 模拟控制混入用户界面 | 身份/故障/接收方模拟仅在 `?review=1` 出现 | 职责分离 |
| 弹框键盘操作不完整 | 初始焦点、Tab 循环、Escape、背景 inert、关闭返回触发点、表单标签关联 | 可访问性 |
| 外部字体导致离线测试加载不稳定 | 移除外部字体请求，采用系统字体回退 | 减少依赖、KISS |
| 常识说明、系统术语与重复提示过多 | 删除退出不删数据等保证；精简聊天、联机、好友、群管理与设置说明，保留危险影响、错误原因及下一步；技术边界移至帮助 | 信息优先、KISS |
| 精简文案误扩大为取消未入房退出确认 | 恢复所有状态下的退出确认，仅有房间活动时补充语音/联机中断说明，复用统一退出清理逻辑 | KISS、DRY |

单文件分享版：运行 `npm run share`，输出根目录 `tmp/weavora-prototype.html`，约 124 KB。构建器只内联现有样式与脚本，不复制实现、不增加依赖，遵循 DRY、KISS。将 `PROTOTYPE_ENTRY` 指向该文件运行同一测试，在本机浏览器 `file:` 模式与模拟断网条件下 140 项断言通过、无脚本异常，包含资源内联、无外部加载、断网重载和完整交互回归。文件可独立发送、下载后用桌面浏览器打开；移动端文件管理器或聊天应用内预览未验证。此产物不纳入 Git，源文件变化后应重新构建。

群邀请布局整改：标题区仅保留“创建群组”，邀请入口移到“我的群组”列表工具栏右侧，降低视觉权重；待处理数量大于零才显示角标，不改变邀请处理逻辑（KISS、YAGNI）。已重新构建分享 HTML（约 125 KB）并在文件模式、模拟断网下完成 146 项断言，无脚本异常；新增验证入口归属、待处理/零数量状态、1440/900/600 px 对齐及无横向溢出。已目视检查 1440 px 和 600 px 群组截图；布局适配不代表移动端平台验收。

退出确认恢复：按用户明确确认，退出登录始终弹出“退出登录？”及“取消 / 退出登录”；未入房不增加说明，有房间活动时保留中断影响，不恢复常识性保证文案。仅修改确认入口，复用原有退出处理（KISS、DRY）。分享 HTML 已重建；文件模式、模拟断网下最新 149 项断言通过，无脚本异常，覆盖未入房确认、取消及 Escape 不退出，以及入房、连接中和断线恢复状态的既有回归；语法检查、空白检查与 B1 门禁通过。

B1 的 CLI 目前不支持登记和运行 F/G/H 的 `verify` 检查；因此本轮浏览器结果来自真实终端执行，不伪造 `tests/evidence/`、审批或执行器证据。后续开发测试阶段必须通过正式 CLI 保存绑定代码树的证据。
