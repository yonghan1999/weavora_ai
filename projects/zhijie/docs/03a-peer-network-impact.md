## 拟定职责

| 组件 | 职责 | 流量与数据边界 |
| --- | --- | --- |
| Java 控制面及其数据库 | 账号、好友、群籍、房间、活动、设备代次、地址分配、当前授权、信令与只读管理记录 | 承担必要控制请求、心跳、授权更新和审计；业务正文及附件是否完全不保存依用户存储选择确定；不承载语音、游戏与附件转发 |
| Lighthouse | 授权范围内节点发现、端点信息和打洞协调 | 不启用业务 Relay；不缓存消息和附件；不能代替应用授权或永久持久化服务 |
| 客户端网络 Helper | 加密虚拟网络、同群/同活动隔离、真实直连状态、受限应用传输接口、当前授权及撤销执行 | 通过客户端之间的物理网络传输；不提供默认网关或物理 LAN 转发；不扩大为任意网络代理 |
| 客户端消息与文件模块 | 本地持久化、同范围成员同步、重传去重、附件校验、下载与播放 | 不使用运营方媒体存储；源或其他有副本成员离线时可能不可获取，不展示为文件丢失或已成功同步 |
| 客户端语音模块 | 采集、编码、通过虚拟 IP 发送、接收、混音、设备与音量控制 | 不使用 LiveKit/SFU/TURN；候选为经虚拟网络发送的 Opus 实时音频协议，须验证时序、抖动缓冲、丢包及拥塞处理 |

控制面数据库属于控制面内部依赖，不是独立业务通讯服务。注册邮件、安装包分发、签名和更新所需外部依赖仍需单独说明；此方案不自动消除这些交付需求。

## 必须明确的产品边界

### 直连失败

默认候选：仅直连，无服务端回退。对称 NAT、CGNAT、严格防火墙或禁 UDP 环境可能无法建立某些成员间连接；Lighthouse 不能保证全网打通。客户端展示实际的逐成员可达性、原因和重试，不能因有虚拟 IP 就显示语音/联机成功。若未来要求所有此类网络也可用，需要用户重新允许中继及相应服务器流量。

### 客户端带宽与 16 人语音

全网状语音时，每个发言端向另外 15 人发送音频。示例以单路编码载荷 32 kbit/s 估算，每个发言端仅音频载荷上行约 480 kbit/s，另有加密、UDP/IP、包头和重传/冗余开销；全部发言时接收端还需接收和混音 15 路。该数字不是实测或保证。大文件传输须限速、背压和降低优先级，避免挤占语音及游戏；容量测试必须包含家庭上行和多个同时发言/传文件端。

不默认指定房主充当中央转发节点。若后续采用客户端转发或主机模式，需要单独设计其上行、离线、迁移与信任边界。

### 群历史与附件（用户已选择客户端保存）

1. 完全客户端保存：有授权的在线副本时同步；全部副本离线时显示暂不可用。无持久副本或设备数据丢失时不能承诺恢复。
2. 控制面只保存文字：文字可随时补读，但仍有文字存储/同步流量；附件依赖在线副本。
3. 任意时间离线可读：必须存在持续在线且有副本的数据源，例如运营方存储或用户自管常驻节点。仅有控制面与不存内容的 Lighthouse 无法提供该保证。

用户已明确选择第 1 项；第 2/3 项仅是比较背景，不纳入当前方案。新需求区分本机保存、对端持久接收及部分送达；无在线副本暂不可用，最后副本丢失不承诺恢复。其他默认细节须人工审批新基线，不能沿用旧服务端保存成功含义。

### 权限、撤销和传输隔离

Lighthouse 发现记录和长期网络证书不能独立承担群籍、单活动和 5 秒撤销。候选采用控制面签名的短期权限租约，绑定账号、设备、群/活动、活动代次、成员代次和允许操作；受支持客户端 Helper 在连接建立、每次发送/接收、续传和持续传输中检查当前租约，撤销后关闭会话并清除对应授权。失联后不能无限沿用旧授权；租约时限、刷新频率、时钟处理和切换屏障须通过实验确定，不能直接宣称符合 5 秒目标。

已下载副本不能保证远程抹除。两个恶意或被修改客户端持有的数据、密钥及在本产品外进行的通信不能由控制面追溯阻止；验收需清楚界定受控端、凭据、旧代次和拒绝服务的安全边界。

群聊天仍需在未入房时可用，不能为了群文件传输让不同房间互通游戏端口。群应用传输范围与房间虚拟网络范围必须隔离；候选为受限应用传输接口与按作用域的隧道/过滤，须验证具体引擎对多作用域、动态授权、地址稳定和隔离的支持。Nebula 证书绑定身份/IP 的方式不能未经验证套用原活动动态 IP 模型。

单一虚拟网络成为语音和游戏的共同底层；音频设备或语音协议故障可独立恢复，但底层隧道不可用时语音也不可用。原 REQ-017 的独立失败语义需重新明确，不能保留旧“双数据通道完全隔离”结论。

### 文件安全与治理

没有媒体服务器时，格式、尺寸、像素和视频时长探测移到客户端的隔离环境；接收端不信任发送端自报 MIME 或“已扫描”声明，必须本地复核、限量接收并禁止主动执行。媒体大小和播放限制可以保留，扫描实现与验收要调整；10 GiB 原服务器群配额需要重新定义为本地缓存预算或全群逻辑引用预算，不能凭去中心化副本数量宣称实现全群磁盘上限。

删除/代删可由控制面记录签名 tombstone 和审计元数据，经对端同步执行；附件正文仍由客户端持有。需要设计断线节点重连时先同步撤销再提供内容，防止旧副本成为绕过入口。15 分钟草稿、24 小时临时对象清理须改为客户端策略并明确离线/关机时限，不能沿用服务器定时任务保证。
