## 完成定义

1. 任务承诺的实际代码、配置和自动化测试位于项目 `workspace/`，没有只写接口说明或静态片段代替实现。
2. 所有前置任务已完成；登记的测试命令在 `workspace/` 真实执行且退出码为 0，证据哈希和任务上下文匹配。
3. 当前任务的权限、异常、幂等、代次和秘密保护边界有相应测试；关键数据库并发使用真实 PostgreSQL。
4. 已批准原型/UI 资产保持可追踪，生产代码不包含模拟授权、定时成功、故障注入或伪造设备数据。
5. 外部邮件、SFU、真实 TUN、直连/Relay、三平台安装签名、音质和容量只有取得对应实测证据才标为通过，否则明确记录未验证。
6. 无临时占位、跳过的必需检查、开放缺陷或未说明的架构偏差。候选替换若改变架构边界，先提交 ADR 和影响评估，不静默换栈。

## 测试要求

- **任务级测试**：每个 TASK 使用上表登记命令；服务端运行 Maven 测试，Rust 运行对应 crate 测试，UI 和工具运行 npm/Node 测试。测试必须覆盖正常路径和该任务的关键失败路径。
- **持久化与并发**：第 13 人拒绝、保留占额、单活动设备争抢、IP 唯一、事务回滚和 Outbox 原子性必须连接真实 PostgreSQL 并执行同一 Flyway 迁移。
- **契约与集成**：TASK-013 验证登录、入房、双通道独立故障、恢复和撤销的控制流；外部服务不可用时记录未验证，不用 Mock 结果宣称 AC-017、AC-020、AC-026 等真实能力通过。
- **安全**：覆盖水平/垂直越权、跨房与跨活动、旧代次/旧策略、重复请求、迟到结果、秘密日志扫描、Helper 请求白名单和 Relay 目标伪造。
- **真实能力与性能**：后续按 C0～C4、SP-01～SP-12 和 AC-001～AC-044 制定独立用例。12 人 60 分钟、100 人在线、100 人分房、5 秒撤销、15 秒恢复、弱网音质和目标 2 核/2 GB/5 Mbit/s 环境分别留存原始结果。
- **跨平台与发布**：Windows、macOS、Linux 分别以实机证据更新矩阵；系统互通与游戏互通分开记录。安装、更新、卸载、Helper 权限、签名和许可证均须核验。
- **当前环境缺口**：2026-11-04 检测到本机 Java 8、Maven 3.9.9、Cargo 1.85.1、Node 24.20.0；架构要求 Java 21+，因此 TASK-001 必须先提供受支持的 Java 21 本地运行方式。当前没有已接入邮件账号、签名证书及已记录的 macOS/Linux 实机结果，不得跳过这些验证边界。

## 风险和回退策略

| 风险 | 控制与回退 |
| --- | --- |
| Java 21 缺失或 2 GB 共置资源不达标 | 先固定受支持运行时并执行 C0/C1；不降低一致性或暗改容量目标。服务端实质替换须独立 ADR 和重新评审。 |
| Tauri、媒体 SDK 或 Rust WireGuard 候选不满足真实能力 | 保持 Command/Event、授权代次和安全边界，修复或比较具体候选；替换容器、引入 Go 或改传输须提交 ADR。 |
| 数据库迁移或并发变更影响既有数据 | 单向 Flyway 迁移，执行前备份；通过恢复备份或前向补偿回退，不原地改已执行脚本、不物理删除业务数据。 |
| 撤销、策略切换或迟到连接造成旧资格复活 | 以权威事务和代次优先，停用新授权入口并保留 Outbox 重放；不得通过关闭撤销、校验或隔离检查回退。 |
| Helper/Relay 回退影响系统网络 | 停止对应会话并清理自身 TUN、路由和 Peer；不修改默认路由、DNS、物理 LAN 或启用互联网代理。 |
| 外部邮件、证书、设备、目标服务器缺失 | 保留适配接口和验证工具，相关项标未验证；不自动采购、部署、扩容或用模拟证据替代。 |
| 单任务回退波及其他通道 | 按 `tasks/tasks.json` 的任务级回退执行，优先功能开关和代码版本恢复；语音与网络独立降级，授权和撤销安全控制始终保留。 |
