## 实际验证

在 `projects/zhijie/workspace/design/ui/` 执行：

1. `node --check build-share.cjs`、`node --check presentation.js`、`node --check test-ui.cjs`：均退出码 0。
2. `npm test`：退出码 0。测试先构建单文件 UI，再复用当前 B1 全量浏览器回归，最后检查独立 UI 入口和工作台。
3. 共享交互回归 185 项、UI 专项检查 45 项，共 230 项通过，脚本异常为 0。浏览器为 Windows 本机 Chrome，无头模式；覆盖 1440×900、900×900、600×900 及 B1 回归中的 900×800、600×800 视口。
4. 185 项共享检查覆盖 CA-01～CA-12：12/13 人边界与保留占额、两通道容量拒绝、降噪/设备测试、三类运营策略与版本切换、恢复/失权/迟到事件、群文字共享和跨群隔离，以及既有账号、权限、治理、设置和响应式路径。
5. 45 项 UI 检查覆盖指定文字/表面对比度、主按钮对比度、键盘焦点、内联错误、无需悬停的入口、12 人滚动与发送区、独立失败重试、退出确认、减少动态、无横向溢出、工作台和单文件离线运行。
6. 已实际查看本轮 `ui-room-capacity.png`、`ui-room-1440.png`、`ui-room-600.png`、`ui-settings-1440.png`、`ui-settings-600.png` 和 `ui-network-failure.png`。12/12 与 3/12 显示一致，满房成员区可滚动，群受众与发送区可见，降噪及模拟边界明确，IP 和独立错误未裁切，未发现整页横向溢出。

这些结果只证明模拟界面路径与指定视觉检查可运行，不是真实媒体、网络、安全、持久化、性能、辅助技术或跨平台验收，也不替代人工走查与审批。B2 暂无正式 F/G/H 的 CLI 执行证据，未伪造 `tests/evidence/` 文件。
