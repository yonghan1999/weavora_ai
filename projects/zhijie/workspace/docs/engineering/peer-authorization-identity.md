# Peer 租约身份与授权到期

## 缺口与复现

批准架构要求 Peer 更新与转发同时受当前成员代次、租约和策略约束，失权后删除旧 Peer，不能只凭旧 IP 或密钥继续通信。控制面原本已返回 `memberGeneration`、`leaseId`、`expiresAt`，但 Helper 的 `NetworkPeer` 仅反序列化账号、IP、公钥和候选端点；路由按 IP/公钥/端点复用 WireGuard 状态，忽略授权身份及期限。

`target/peer-authorization-b4ad8b0/before.log` 在修改生产代码前取得两项失败：相同 IP/公钥/端点切换成员代次及租约后仍显示已认证；远端授权到期后仍显示连接并能尝试发送。原路由其余四项测试通过，不把所有失败归因环境。

## 实现

- `NetworkPeer` 将成员代次、租约与绝对到期设为必需字段；没有安全默认值，缺字段响应拒绝。
- 路由先校验完整快照，拒绝空账号/租约、零代次、重复账号、低于当前集合的成员代次及错误期限；未通过校验不删除仍有效的集合。已到期的合法条目不安装。
- 只有账号、成员代次、租约、IP、公钥、候选端点均相同且旧授权尚有效，才复用 WireGuard 握手；同身份正常刷新可更新期限，不打断每分钟签票。任一身份变化或旧授权已过期则新建会话。
- 绝对期限在收到快照时转换为单调时钟，转换后不因墙上时钟倒退延长这次授权。出站、直连入站、中继入站和定时握手均移除到期 Peer；生成网络动作与解封明文时再次检查，状态不把近期流量误当持续授权。
- 控制面列表返回票据和当前租约两者的较早期限，不因票据尚有效延长较短租约；无需新数据库迁移、依赖或接口路径。

复用原路由表、权威快照和 WireGuard 实现，统一到期清理与最终动作检查；不新增缓存系统或新传输协议，遵循 KISS、DRY、单一职责和 YAGNI。
