# 登录失效后的真实语音停流

## 验证范围

接续 `8471c58` 的活动登录绑定修复和 `d05c3a7` 的网络数据面验证，本轮增加真实 SFU 媒体验证，不修改产品源码、期限、迁移、依赖或试用包。控制面 403、SDK 断开事件和 Outbox delivered 均不单独作为音频停流证据。

新 `VoiceSessionRevocationIntegrationTest` 通过真实 HTTP 登录创建三名用户，使用已鉴权 `AuthSession` 加入同一活动并签票，再正常刷新目标登录；确认旧语音票据继续可用后建立媒体。三种失效分别为真实 HTTP 注销、刷新旧令牌重放和独立临时数据库中目标会话到期；到期只改目标登录的 `expires_at`，不改活动、租约、grant 或事件，不冒充等待三十天自然到期。

本机既有 LiveKit、nginx 权威信令入口、PostgreSQL、Spring 和 Rust LiveKit/WebRTC SDK 实际参与。管理密钥不传给媒体探针，探针只接收三张参与者短票；没有手动调用清退器、Outbox dispatcher、SFU RemoveParticipant 或客户端 Stop。生产每秒扫描、持久清退、同步事件和语音管理 HTTP 自动执行。

## 真实媒体断言

三端分别持续发布 48 kHz 单声道受控 PCM，全部六个接收方向实际解码至少二十个非静音帧，才通知父进程撤销认证。不是仅检查订阅或连接成功。目标端发布任务在失权后仍持续尝试至少一百帧，三个音源都不主动静音或停止。

撤销确认后观察约 3.5 秒：目标 SDK 被服务端断开，四个涉及目标的收发方向在最后 500 ms 内非静音帧不再增加，健康两方向各新增至少二十帧，健康成员不被断开。父进程从真实撤销事务返回计时，要求隔离信号五秒内到达，并检查目标租约/grant/活动指针清退、唯一 `voice.revoked` 事件真实 delivered。撤销前票据至少还有十秒有效期，隔离后仍未自然过期；旧票经真实 nginx/控制面校验返回 403，健康票返回 200，目标实际 SDK 重连也被拒绝。

持续发布计数表示调用原生 PCM 捕获，不能声称 SDK 在服务端关闭后仍成功向网络发出 RTP；验证的是不依赖应用主动停止的服务端隔离。窗口统计非静音 PCM，不把无声回调冒充数据面通流或断流。
