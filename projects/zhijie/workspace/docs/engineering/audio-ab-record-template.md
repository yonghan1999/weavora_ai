## 固定处理链与样本

**离线软件降噪对照，不是设备通话验收。** Windows 桌面当前使用 `RtcAudioSource::Device`；锁定的 WebRTC 原生工厂在创建设备轨道时请求启用软件降噪，SDK 的单项开关操作硬件降噪（设备不支持时可直接返回成功）。因此不能只凭返回值将两次麦克风录音标成“软件关/开”。当前桌面不提供经过此验证的实时软件降噪开关。

可从 workspace 对已有且获准使用的输入录音做独立的软件 A/B。输入须为**无 WAV 头的单声道、48 kHz、有符号 16 位小端 PCM**，且长度为完整的 10 ms 帧。使用 D 盘专用目录；不读取麦克风、不联网、不覆盖原录音或既有输出。输出目录须不存在，上级目录须已存在；命令失败时不要使用不完整的输出。示例不打入桌面安装包。

```powershell
cargo run --locked --offline -p zhijie-voice --example compare_noise_suppression -- "D:/audio-test/input.s16le" "D:/audio-test/comparison-001"
```

`ns-off.s16le` 和 `ns-on.s16le` 是相同格式、长度的两份输出。两个独立 APM 从相同的初始条件处理相同的输入帧，均关闭回声消除、自动增益和高通，只改变软件降噪设置。此处没有 SFU、编解码、设备驱动、丢包或真人听辨，不能作为下面场景表的通过记录。真实录音留在授权目录，不提交 Git。

本机工具校验：`target/software-ns-20261120-033424/comparison.json`。3 秒固定种子的合成稳态噪声（300 帧），末秒 RMS 从 2892.09 降至 501.91（PCM 幅值单位）；关闭输出与输入 SHA-256 一致，开启后输出非静音且摘要不同。仅说明软件开关影响了这个样本，不证明人声清晰或游戏通话已降噪。构建后可运行 `python -B "scripts/test-software-noise-comparison.py" "<本次构建的示例可执行文件>"` 复核。
