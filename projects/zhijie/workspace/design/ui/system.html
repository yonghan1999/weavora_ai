交互规范 / COMPONENT CONTRACT

不是一张效果图。
是一套可执行的界面规则。

产品页面承载真实任务，工作台展示组件契约。这里的失败、等待和完成均为本地模拟，不代表真实服务能力。

视觉基础操作层级连接状态表单反馈开发契约

01 / 视觉基础

色彩按用途命名；页面与组件共用同一套令牌，不凭局部喜好添加颜色。

工作区--bg
内容表面--panel
主要操作--accent
错误 / 危险--danger

房间名是视觉锚点

正文服务于任务，保持清晰、克制、不反复解释常识。

辅助信息使用 12px；IP 用等宽字体。10.66.0.12

02 / 操作有轻重

同一任务区域只有一个最强主操作；管理入口弱化，危险操作与主操作分离。

可使用 Tab、Enter 检查焦点与按钮状态。

03 / 状态不是换一个颜色

语音与联机各自拥有连接状态。一项失败不能冒充另一项失败，也不能直接显示成功。

语音未连接语音连接中语音已连接虚拟网络连接失败
语音已连接这一通道不受联机重试影响
虚拟网卡权限不足模拟已授权场景，点击后演示重试过程

04 / 错误留在现场

不清空输入；说明具体原因；光标回到错误字段；用户修改后移除旧错误。

05 / 开发交付契约

加入房间

点击 → 权限/容量/密码校验 → 独立连接中 → 各自成功或失败。失败保留旧有效活动。

退出登录

始终二次确认。只有房间活动仍存在时附加语音和联机中断影响；取消、关闭、Escape 均不执行退出。

不可逆操作

确认前展示对象与损失。群解散输入名称校验；删除失败不得先从界面移除后宣称完成。

设计不等于实现

状态样例不是后端成功证据。真实授权、持久化、并发及设备操作在后续阶段实现与独立验收。
