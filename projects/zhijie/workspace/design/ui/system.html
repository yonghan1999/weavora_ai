01 / 视觉基础

色彩按用途命名；页面与组件共用同一套令牌，不凭局部喜好添加颜色。

工作区--bg
内容表面--panel
主要操作--accent
错误 / 危险--danger

房间名是视觉锚点

正文服务于任务，保持清晰、克制、不反复解释常识。

02 / 操作有轻重

同一任务区域只有一个最强主操作；管理入口弱化，危险操作与主操作分离。

可使用 Tab、Enter 检查焦点与按钮状态。

04 / 副本与送达

仅客户端保存内容，控制面不存正文或附件；最后副本丢失不保证恢复。群内容无需入房即可同步，不能开放跨房游戏或语音。

无在线可达副本 · 缺失内容暂不可用

本机保存 · 待同步（模拟）

缺失内容用占位说明，不以空列表假装同步完成；已删内容不得因副本上线复活。10 GiB 是群附件逻辑引用预算，客户端磁盘满时拒绝接收。

05 / 错误留在现场

不清空输入；说明具体原因；光标回到错误字段；用户修改后移除旧错误。

06 / 开发交付契约

加入房间

点击 → 权限/容量/密码校验 → 建立虚拟隧道 → 隧道就绪后连接语音。目标校验失败保留旧有效活动；逐成员不可达须如实显示。

退出登录

始终二次确认。只有房间活动仍存在时附加语音和联机中断影响；取消、关闭、Escape 均不执行退出。

消息与媒体

选择 → 本地预览 → 客户端直传 → 接收端校验与落盘 → 对端已接收。无对端则本机保存/待同步；元数据登记不等于送达。等待防重复，失败保留预览与附言。

不可逆操作

确认前展示对象与损失。群解散输入名称校验；删除失败不得先从界面移除后宣称完成。

设计不等于实现

状态样例不是后端成功证据。真实授权、持久化、并发及设备操作在后续阶段实现与独立验收。
